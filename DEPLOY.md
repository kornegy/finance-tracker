# Как запустить приложение в Telegram

Понадобится примерно 15 минут и три сервиса: GitHub (код уже там), Telegram (бот) и Render (хостинг).
Хостинг нужен потому, что Telegram открывает Mini App только по публичному адресу `https://`.

## 1. Создайте бота

1. В Telegram откройте [@BotFather](https://t.me/BotFather) и отправьте `/newbot`.
2. Введите имя бота (например, `Мои расходы`), затем username, который заканчивается на `bot` (например, `my_expenses_123_bot`).
3. BotFather пришлёт **токен** вида `1234567890:AAH...`. Сохраните его. Это пароль от бота: никому его не отправляйте и не коммитьте в git.

## 2. Разверните приложение на Render

1. Зарегистрируйтесь на [render.com](https://render.com) через кнопку **GitHub**.
2. В панели Render нажмите **New → Blueprint**.
3. Подключите репозиторий `kornegy/finance-tracker`. Если его нет в списке, нажмите **Configure GitHub** и дайте Render доступ к этому репозиторию.
4. Render прочитает файл `render.yaml` и покажет, что создаст веб-сервис `finance-tracker` и базу данных `finance-tracker-db`.
5. Render попросит значение **`Telegram__BotToken`**. Вставьте токен из шага 1.
6. Нажмите **Apply** (или **Deploy Blueprint**). Первая сборка занимает 5–10 минут. Когда она закончится, у сервиса появится статус **Live**.
7. Откройте сервис `finance-tracker` и скопируйте его адрес вверху страницы, например `https://finance-tracker-abcd.onrender.com`.

Проверка: откройте в браузере `https://<ваш-адрес>/health`, должно показаться `{"status":"ok"}`.
Если открыть просто `https://<ваш-адрес>`, появится надпись «Откройте приложение в Telegram». Так и должно быть.

## 3. Подключите приложение к боту

1. В [@BotFather](https://t.me/BotFather) отправьте `/mybots` и выберите своего бота.
2. **Bot Settings → Menu Button → Configure menu button**.
3. Отправьте адрес из шага 2.7 (`https://finance-tracker-abcd.onrender.com`).
4. Отправьте название кнопки, например `Расходы`.

## 4. Откройте приложение

Откройте чат со своим ботом (ссылка вида `t.me/<username_бота>`), нажмите **Start**, затем кнопку **Расходы** слева от поля ввода. Приложение откроется, и можно добавлять расходы.

## Полезно знать

**Валюта** выбирается прямо в форме, справа от суммы: Kč, €, $, ₴ или ₽. Приложение запоминает последнюю выбранную.

**Бесплатный тариф Render** (условия могут меняться, проверьте актуальные на render.com/pricing):
- если приложением не пользоваться ~15 минут, сервис «засыпает», и следующее открытие займёт до минуты;
- бесплатная база PostgreSQL на Render работает ограниченное время (раньше это было 30 дней), потом её нужно перевести на платный тариф. Иначе данные будут удалены. Если нужно бесплатно и надолго, можно создать базу на [neon.tech](https://neon.tech) и вставить её строку подключения (`postgresql://...`) в переменную `ConnectionStrings__Postgres` в Render. Приложение понимает такой формат.

**Обновления.** Каждый push в ветку `main` Render разворачивает автоматически, миграции базы применяются при старте.

## Если что-то не работает

| Что видно | Что сделать |
|---|---|
| «Не удалось войти. Закройте и снова откройте приложение.» | Проверьте, что `Telegram__BotToken` в Render → Environment совпадает с токеном бота из BotFather. После правки Render перезапустит сервис. |
| «Откройте приложение в Telegram» внутри Telegram | Кнопка меню ведёт не на тот адрес. Повторите шаг 3, адрес должен начинаться с `https://`. |
| Долго грузится при первом открытии | Бесплатный сервис просыпался. Подождите минуту. |
| Сборка на Render упала | Откройте сервис → **Logs** и пришлите мне последние строки. |
